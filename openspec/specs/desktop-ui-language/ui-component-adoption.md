# UI组件规范采用说明

[Piwork UI Component Specification v1.0](ui-component-spec-v1.0.md) 是项目所有者于2026-10-14直接提供并要求后续UI开发遵循的产品级组件选型依据。原文保持不改；其中Proposed是来源文件原始状态，不代表仍等待采用授权。

采用原则：先判断任务/作用域/中断性，再选择交互模式与容器，最后考虑样式。新增或修改UI按规范审查，优先修复具体的语义误用与真实使用障碍。采用本规范不授权一次性重写全部UI、引入组件库/设计系统、自动化LINT-UX流水线、命令面板或其他新功能。

所有者同时明确“不要过度设计”：无障碍条目用于指导正确组件、基本键盘和焦点行为，不是本次工作的独立最终目标，也不表示已完成WCAG认证、全量触屏或读屏矩阵。按实际影响验证并报告未测；审查清单不等于默认全量承诺。

后续更具体、更新的用户要求优先于一般默认值。例如当前所有Modal开关动画保持移除；Show/Hide Chat归Service Header同一位置，不能再复制到Work导航。既有Core/API、安全权限、危险操作确认、异步写锁及草稿连续性不能为了表面组件一致而弱化。

此文件及规范是稳定开发入口；每次具体变更仍在所属OpenSpec change记录范围、例外和实际验证结果，不以采用规范为由自动归档或同步无关delta。
