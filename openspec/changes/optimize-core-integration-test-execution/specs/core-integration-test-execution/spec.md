# Spec Delta

## Purpose

定义 Core 集成测试在不同开发机和 CI 环境中的完整执行、隔离、进度与结果证据，使调整并发和缩短反馈不会改变覆盖、候选身份或成功判定，也不要求任何特定机器配置才能验证产品正确性。

## ADDED Requirements

### Requirement: 完整验收按显式清单执行一次

**Identifier:** CITE-001

完整入口 SHALL 从当前候选的实际测试发现结果建立全量清单，每个顶层用例恰好分配到一个执行位置，并保留原子场景。指定的必须通过回归子集 SHALL 从同一全量结果核对，不强制在完整验收前重复执行。缺项、重项、未知用例或未执行用例 MUST NOT 被判定为完整通过。目标模式 SHALL 明确标记为局部结果。

#### Scenario: 全量包含原回归子集
- **WHEN** 运行完整验收且原 16 项回归均存在于清单
- **THEN** 每项只执行一次并从全量结果核对其通过证据，不追加重复目标组

#### Scenario: 仅运行目标组
- **WHEN** 维护者显式选择局部回归
- **THEN** 结果标记为目标模式，不能替代完整验收

#### Scenario: 分配遗漏或重复
- **WHEN** 分片遗漏某用例、重复包含某用例或运行了未知用例
- **THEN** 汇总明确失败并列出差异，即使其他用例全部通过

### Requirement: 并发策略可移植且不改变测试语义

**Identifier:** CITE-002

运行器 SHALL 支持串行、显式正整数并发和保守自动调度，记录请求值与实际值。资源信息只影响调度，不决定产品正确性、清单或跳过条件；探测不可用时 SHALL 可回退串行。相同候选和条件在不同合法并发配置下 SHALL 使用相同覆盖与判定，不要求指定 CPU、内存、主机、固定 worker 数或跨设备绝对耗时。

#### Scenario: 单 worker 与多 worker
- **WHEN** 同一候选分别用串行及合法多进程配置执行
- **THEN** 清单与必须通过项保持一致，报告实际调度差异

#### Scenario: 资源信息不可用
- **WHEN** 自动策略无法可靠取得可用资源限制
- **THEN** 以可解释的保守配置继续，不跳过测试或仅因此判断产品失败

#### Scenario: 非法并发输入
- **WHEN** 显式并发值为零、负数、非整数或不受支持的格式
- **THEN** 在启动测试资源前拒绝并给出安全说明

### Requirement: 同一验收固定输入并复用不可变准备

**Identifier:** CITE-003

全量及其分片 SHALL 关联同一源码输入、测试二进制、工具链、有效测试配置和实际不可变镜像身份。相同输入的构建与准备 SHALL 在调度前协调复用；运行中输入漂移、准备失败或制品不匹配 MUST NOT 产生该候选的完整通过证据。运行结果不得从旧候选缓存冒充执行，安装数据与凭据不得作为共享准备制品。

#### Scenario: 多分片使用同一制品
- **WHEN** 同一候选被分配到多个 worker
- **THEN** 复用已确认匹配的不可变准备，每个测试仍创建自己的安装数据

#### Scenario: 运行中修改镜像引用
- **WHEN** 可变标签所指镜像或源码输入在冻结后发生变化
- **THEN** 原结果保留并标记输入不一致，不宣称新输入已验收

#### Scenario: 缺少必需历史夹具
- **WHEN** 必须通过回归所需的真实历史镜像不可用
- **THEN** 前置检查失败，不通过条件 skip 将该回归算作完成

### Requirement: 测试 RPC 端口按安装隔离并保持重启关联

**Identifier:** CITE-004

测试安装 SHALL 获得彼此隔离且由启动夹具管理的 RPC 监听资源，实际监听与下发回连地址 SHALL 一致。同安装重启 SHALL 保持存活 Agent 可用的端口关联；冲突不得通过静默换端口、盲目重试或借用另一安装来掩盖。Core 退出后不得因夹具仍持有监听副本而伪造可用。生产默认 7172、既有运行参数及 mTLS 身份边界保持原契约。

#### Scenario: 两个 Core 测试安装并发
- **WHEN** 两个独立安装同时启动真实 Core 与 Agent
- **THEN** 使用各自的监听及回连地址，身份和控制请求不跨安装混用

#### Scenario: 同安装异常退出后重启
- **WHEN** Core 崩溃但该安装原 Agent 仍存活
- **THEN** Core 重启复用原端口关联，核验原身份恢复回连，不启动额外主 Agent

#### Scenario: 安装停止与端口冲突
- **WHEN** Core 停止或原端口被安装外进程占用
- **THEN** 前者真实释放该 Core 的监听；后者明确失败，不结束无关进程或自动换地址

### Requirement: 并行执行保留安装和独占资源边界

**Identifier:** CITE-005

互相独立的分片 SHALL 具有进程级环境隔离及测试级 installation、数据、网络、卷与凭据隔离。共享外部资源的用例 SHALL 声明并遵守互斥约束；要求无并发压力的真实性能用例 SHALL 在无冲突负载阶段执行。并发准入不得绕过产品配额、身份、未知状态或停止确认；失败不得跳过本次其他资源的有界清理。

#### Scenario: 不同测试修改进程环境
- **WHEN** 两个用例使用不同 PATH 或测试镜像配置
- **THEN** 修改仅影响所属测试进程，不污染其他分片

#### Scenario: 性能测试与普通集成争用
- **WHEN** 用例要求无其他并发压力
- **THEN** 调度器等待冲突负载结束，保留原采样及判定条件

#### Scenario: 某分片失败
- **WHEN** 一个 worker 异常退出
- **THEN** 汇总失败并按精确归属清理本次资源，不删除其他安装或依赖全局 prune

### Requirement: 提前完成的有界等待释放兜底资源

**Identifier:** CITE-006

被测生命周期等待在实际完成、失败或取消后 SHALL 释放不再需要的兜底定时器和观察资源，不能仅因残留计时器继续阻塞进程退出。未完成分支 SHALL 保持原超时、取消、错误及停止确认语义；不得为缩时强制退出、吞失败或修改产品默认关闭预算。

#### Scenario: MCP 在兜底期限前关闭
- **WHEN** MCP 关闭已实际完成
- **THEN** 不再保留该等待的兜底计时器阻止自然退出

#### Scenario: MCP 关闭仍未结束
- **WHEN** MCP 关闭没有完成确认
- **THEN** 仍按原有界策略收尾，不因测试提速而伪造确认或无限等待

### Requirement: 结果和实时进度来自实际测试事件

**Identifier:** CITE-007

运行器 SHALL 从实际进程和结构化测试事件报告候选、阶段、当前用例、完成状态、耗时及包级结论。异常退出、编译失败、超时、中止、缺失终态及无法解释的 skip MUST NOT 计为完整成功；必须通过子集不得跳过。重试须显式保留原失败，不自动重复业务操作取得绿色。命令结果不依赖 OpenSpec 勾选状态，也不自动修改任务或归档。

#### Scenario: 所有已显示用例通过但包失败
- **WHEN** 测试进程返回失败或缺少包级成功终态
- **THEN** 总结仍失败或不完整，不仅按 PASS 数量判定

#### Scenario: 存在可选场景条件跳过
- **WHEN** 某非必需场景按已有有效条件 skip
- **THEN** 保留场景、条件和原因，不能用统一跳过规则隐藏缺依赖的必需场景

#### Scenario: 用户中止运行
- **WHEN** 运行被取消
- **THEN** 记录中止、已执行与未执行项及清理结果，不写入成功结论

### Requirement: 缩时效果以可解释的同条件对照验收

**Identifier:** CITE-008

耗时报告 SHALL 分列构建、准备、执行、清理及总墙钟时间，区分冷准备与缓存命中。提速结论 SHALL 基于同环境、同候选、同测试清单的串行与并行对照，记录调度和负载条件及全部失败样本；不得通过删除慢用例、减少数据边界或设备专属的分钟阈值宣称成功。资源受限下仍须保持相同正确性要求。

#### Scenario: 比较缩时前后结果
- **WHEN** 对同一候选完成可比较的串行和并行执行
- **THEN** 同时报告覆盖恒等、实际总墙钟和各阶段变化；无可靠收益证据时不宣称已提速

#### Scenario: 首次冷构建
- **WHEN** 本机需要下载依赖或构建未缓存镜像
- **THEN** 显示真实准备耗时与结果，不隐藏在测试时间之外或因此放宽产品断言
