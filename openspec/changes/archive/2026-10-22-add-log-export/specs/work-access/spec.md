## ADDED Requirements

### Requirement: 仅任务发起管理员可导出平台与自有 Work 日志

**Identifier:** WACC-LOG-EXPORT-001

日志导出创建、状态查询和内容下载 SHALL 只接受当前启用的登录管理员用户会话，且已存在任务只允许原发起用户读取。缺失或无效用户认证返回 401；有效普通用户返回 403，且在创建任务、日志读取或临时文件分配前拒绝。operator credential 和 Agent runtime 身份不得转换或回退为该管理员用户身份。另一个管理员访问任务 SHALL 被拒绝，不因包中包含全局 Core 日志取得原发起者的 Work 内容。

管理员的导出范围 SHALL 为 Core 全局安全平台日志及其自己全部 Work 的保留日志和归档；普通用户没有该导出能力，其他用户 Work 的日志正文仍不因管理员控制权限而开放。范围及归档所有者由 Core 持久归属决定，请求、ZIP 名称、浏览器缓存或 Docker 名称均不能改变归属。既有所有者的有界 Service 日志查看和 Work 快照权限保持原契约。

Core SHALL 在任务执行、发布和下载时复核必要资格；管理员被降权、禁用或会话撤销后不得发布新的内容许可。下载准入及发送前的完整性核验 SHALL 同样受当前资格复核和撤销期限约束，不得在长 hash 校验期间沿用已撤销许可。到期与 GC 竞争不得绕过当前身份、owner 和租约限制。活动下载 SHALL 至少每 2 秒复核当前会话、管理员角色和任务所有者，失效后至多 2 秒开始中断。已生成包不成为可绕过授权的公开链接；同一用户重新取得有效管理员会话后可按原 ID 查询仍保留结果。

#### Scenario: 普通用户调用导出接口
- **WHEN** 有效普通用户创建、查询或下载日志导出，包括猜测存在/不存在的 ID
- **THEN** 返回一致的 403，不创建任务、不读取来源、不分配导出暂存或披露任务内容

#### Scenario: 管理员控制其他用户 Work
- **WHEN** 管理员可以停止另一用户 Work 并发起全局日志导出
- **THEN** 包中包含 Core 安全日志及管理员自己的 Work 来源，不含另一用户的应用日志正文

#### Scenario: 另一个管理员请求原包
- **WHEN** 管理员 B 请求管理员 A 创建的导出状态或 ZIP
- **THEN** 返回 403，不返回 A 的来源清单或 Work 内容

#### Scenario: 下载中被降权
- **WHEN** 发起管理员下载尚未结束时被降为普通用户、禁用或撤销会话
- **THEN** 活动流在约定期限内中断，后续查询/下载拒绝，不凭旧角色缓存继续交付

#### Scenario: 删除 Work 后归档仍有归属
- **WHEN** 管理员删除自己的 Work 后再次导出，另一个管理员也发起导出
- **THEN** 仍保留的归档仅进入原所有者范围，不因 Work 从普通列表消失而变成全局可读日志

#### Scenario: 完整性核验期间撤销身份
- **WHEN** 内容响应尚未发送，慢 hash 核验期间管理员会话被撤销或角色失效
- **THEN** 在约定期限内开始中断，不发送受保护内容；阻塞客户端和到期竞争均不延长旧许可，释放本次引用与下载槽位
