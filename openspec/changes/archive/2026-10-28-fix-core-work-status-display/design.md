# Design

## Context

见 proposal。`internal/cli/user_desktop_api.go` 的状态检查把所有非成功请求视为 Core 不可用，而 `/readyz` 在恢复中返回 503 与可解析的 `RECOVERING`；`internal/coreapp/work_recovery.go` 逐个恢复 Work，`work_start.go` 到启动时才写入 starting，先前持久状态在核实前可能仍可读取。`apps/desktop-webui/src/adapter.ts` 的 Work 观察主要由已知 Operation 和同步需求驱动，自动恢复没有对应用户 Operation。`lifecycle.ts` 和 `app.ts` 负责状态投影与行展示。截图中的 404 尚未复现，不假定其来源。

## Goals / Non-Goals

**Goals:** 为当前进程恢复过程提供可证明的状态，稳定地传递到 Desktop，并按确认的 [原型](prototype/index.html) 呈现；保持已有 Operation 安全和身份约束。

**Non-Goals:** 不更改 Work 持久意图、自动重试业务写入、Operation 历史或 Work 数据；不改变产品整体导航和发行流程。

## Decisions

1. **保留可解析的 readiness 状态。** 调整 Desktop Go 适配读取 `/readyz` 的方式，识别符合契约的 503 响应并保留其状态与原因；传输失败、非法响应和真实失败分别表达。已有状态格式优先兼容，不能仅按 HTTP 状态推断启动。相比统一转为不可用，这能保留 Core 明确的恢复事实。
2. **为恢复确认设置当前进程边界。** 在 Work 列表与详情投影中表达当前恢复尚未核实，并在实际启动、核实成功或失败时更新。Core 在开放监听前，以单一存储事务将上一进程的非终态 observed 状态改为 unknown，保留 desired、版本、错误与数据；当前进程启动、核验或停止完成后由现有事务发布实际状态。这样确认边界与 Work 快照一致，也不把 unknown 伪装成正在启动；已确认的 stopped 目标仍需按真实事实处理。恢复检查与现有路由准入、控制版本和异常关闭协调，不能将展示状态当作授予运行访问的证据。相比按全局 readiness 把全部 Work 强制标为 Starting，这允许已核实 Work 独立呈现。

   运行目标的旧 failed 也须核对最新运行代次：仍可自动恢复或无代次时改为 unknown；最新代次失败且重试预算耗尽时保留 failed。停止目标的失败保持原样，重试计数及截止时间不变。

   当前恢复尝试失败时，在同一事务记录重试预算与 Work 观测：已安排自动重试则发布 unknown，预算耗尽则发布 failed；仅更新仍为 running 的最新代次，避免覆盖新的代次或停止目标。
3. **只读、有界观察恢复。** Desktop 在列表可见且恢复尚未确认时周期性、去重读取 Core 和相关 Work，完成或离开时停止；Core 状态读取复用元数据读取的十秒超时及取消机制，超时后允许手动重查。处理身份切换和过期响应，失败保留最后确认事实但明确未确认。保留既有活跃 Operation 的观察，不创建虚构操作或重发控制请求。
4. **状态与历史分离。** 检查 Work 行及动作反馈的关联和生命周期，仅移除终态历史操作在行内持续出现的投影，保留原 Operation 详情、失败及结果未知的恢复路径。404 按 Work 或 Operation 原始查询分别处理，重现或以有针对性的模拟测试查清来源后修复。
5. **界面采用确认原型的结构。** 搜索、紧凑 Core 状态和操作按钮位于同一工具栏；Core 启动采用轻量动效文字，不展示额外启动 Alert 或 Works 标题。响应式、双语和减少动态效果沿用现有规范；原型是布局参照，真实内容由状态驱动，不照搬其示例数据和交互。

## Risks / Trade-offs

- [恢复观察增加请求] → 仅在可见且有恢复目标时有界、去重轮询，终态停止。
- [启动期间确认边界与旧 Work 数据冲突] → 增加重启、崩溃接管、已停止目标和失败重试测试；不破坏持久目标与代次栅栏。
- [隐藏历史记录导致原操作不可找回] → 仅改变列表展示，验证详情和未知结果恢复路径。
- [截图 404 无法复现] → 先验证具体请求与响应；无法确认时保留事实并记录未测限制，不编造修复原因。

## Migration Plan

无需数据迁移；构建 WebUI 并同步 Go 嵌入资源，运行相关测试。回退代码和嵌入资源即可恢复旧展示，持久意图及操作记录保持原格式。
