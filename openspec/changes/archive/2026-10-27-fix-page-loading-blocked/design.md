# Design

## Context

`apps/ui-shared/boot.js` 是依赖 `i18n.js` 的外部 ES module，只翻译静态占位。Desktop、Admin 和 `/login`／`/setup` 的 HTML 也各自直接引用主模块；任一传递模块失败都可能使主模块完全不执行。三个 HTML 已有无需脚本的刷新链接，但没有自动恢复或失败状态。Admin 在 `apps/console-webui/src/app.ts` 末尾等待 `ConsoleAdapter.initialize()` 和 `connection()` 后才进入 `loadPage()`；`onboarding.ts` 的 `load()` 顺序等待 state、session 等读取。两处 fetch 均无时限，且 Admin 的读取去重表与引导的 `readLock` 可能一直保留悬挂请求。Desktop 的 `adapter.initialize()` 已在十秒后显示重试，但其会话请求本身仍可能悬挂。

当前三个 Go 服务均采用 `script-src 'self'`；普通内联脚本会被 CSP 拦截。HTML、脚本和样式分别由 `internal/webapp`、`internal/consoleapp`、`internal/cli` 提供，构建后的资源由 `internal/consoleassets` 和 `internal/desktopassets` 嵌入。现有会话、草稿、未知写入、UI 和语言契约分别见 `desktop-webui`、`serve-ui`、`web-onboarding`、`ui-language` 和 `desktop-ui-language`。

## Goals / Non-Goals

**Goals:**

- 在模块图运行前检测关键启动失败，并在应用接管后移交给安全的局部读取恢复。
- 在有限时间内让用户得到明确状态、只读重试和当前身份可使用的导航。
- 分别验证真实 Go HTTP 路由、嵌入资源、CSP 和托管／独立 Desktop，而不只测试静态夹具。

**Non-Goals:**

- 不改变身份、CSRF、Work 生命周期、写操作协议、真实长任务等待或普通后台流式连接的时间预算。
- 不保证入口 HTML、服务器响应头或整个浏览器本身无法取得时网页脚本仍可执行；该情况保留浏览器原生恢复。
- 不以串行加载资源掩盖 MicroVM 并发缺陷；Windows 转发层由 `piwork-microvm` 同名变更修复。

## Decisions

### 1. HTML 内自包含的启动哨兵和明确移交

在三个 HTML 入口放置同一份很小的同步经典脚本，置于关键样式和模块资源开始加载之前；它不 import、不依赖外部文件，负责监听资源错误、应用是否已接管和十秒看门狗。应用入口只有在可提供本地错误处理、初始壳和读取重试并且即将开放交互时才发出接管信号；信号先取消任何自动重载计时器，再允许用户输入。接管信号不能仅代表某个模块成功下载，也不能等待远端会话读取结束。对 Admin 需先渲染中性壳并安装处理器；三入口的等待／失败表示按各自 UI 规范实现。

```
HTML + inline watchdog
  |-- critical resource failure or 10s without handoff --> bounded document reload
  |-- app owns shell and recovery -----------------------> local read recovery
  `-- budget exhausted or counter unavailable ----------> static manual reload
```

用带退避的整文档重载恢复未接管时的模块图：首次失败后等待 1 秒、第二次等待 3 秒，最多自动重载两次。重新加载文档会创建新的模块图；对入口 URL 追加查询参数的动态 import 不能可靠刷新所有传递依赖，因此不采用。对每个入口和标签页用 `sessionStorage` 仅保存启动周期、次数等最小控制信息；禁止记录路径参数、表单、身份或秘密。重载前先写入次数，写入失败则不自动重载。预算耗尽后留在静态失败态，手动入口仍直接可用；显式手动重新加载可做一次新尝试，持续失败时不自行重新获得自动预算。成功接管清除该入口预算，正常快速启动不等待十秒。用户手动恢复与接管均取消旧定时器，后到事件不得启动另一重载。

若样式失败时应用已接管，禁止哨兵整页重载；应用在原页面显示可理解的恢复方向并按既有草稿离开保护处理显式重载。HTML 保留无脚本、无 CSS 也可操作的双语重载按钮与首页／返回链接；`/` 可作为三种模式的共同入口，实际认证和重定向仍由服务端判断，不把仅托管模式支持的 `/login` 显示给独立 Desktop。失败发生在 HTML 或 CSP 自身传输之前时，由浏览器原生导航处理。

静态刷新使用没有 `action` 的原生 GET 表单与重载按钮，使浏览器沿用当前路径和片段。服务端在隐藏字段中编码原始请求目标；收到该只读恢复请求后，只允许跳转回相同路径并还原原始查询，片段由浏览器继承。这样不依赖脚本，也不让表单序列化改变重复参数、查询编码或空查询；恢复不能跳往外部来源、其他路径或嵌套恢复请求，不新增业务写操作。脚本可用时继续直接使用 `location.reload()`，取消旧恢复定时器。

### 2. 保持 CSP 并同步嵌入资源

构建阶段从共享源生成一致的内联脚本和其 SHA-256，三个入口通过各自实际 HTML 服务的 `script-src` 仅加入该内容哈希；不启用 `unsafe-inline`、`unsafe-eval`、远程脚本或放宽其他 CSP 指令。构建或测试核对最终 HTML 字节与实际 HTTP 响应头的哈希，覆盖 Admin 重写路径、托管与独立 Desktop、未认证 `/login` 和 `/setup`。原生表单不依赖哈希脚本成功，因此 CSP 不匹配或禁用脚本时仍可手动恢复。`apps/*/scripts/copy-static.mjs` 和 `scripts/sync-*-assets.mjs` 负责同步最终 HTML 与共享资源；Go 宿主重建以保证测试使用嵌入产物。

只增加外部监测脚本无法处理监测脚本本身被拒绝；放宽整个 CSP 可以运行内联代码但改变安全边界，因此均不采用。

### 3. 读取有界、可取消并隔离所有权

在 Desktop `adapter.ts` 的会话读取、Console `adapter.ts` 和 `app.ts` 的首次 session／availability／页面读取、`onboarding.ts` 的 state／session／必要 onboarding 读取，为单次只读尝试统一设十秒截止，覆盖响应头及响应体。优先中止请求，并保证不支持或忽略中止时外层等待仍会在截止时结束；按本次请求、身份和视图的 generation/epoch 核对结果。去重表和锁只由其拥有者释放，超时后下一次显式重试不得重新取得旧的悬挂 Promise。不能让旧 `finally` 释放新锁。

失败或超时时立即在对应局部显示未确认及只读重试；自动尝试最多两次，间隔 1 秒、3 秒。用户显式重试可立即开始新的有限只读周期并取消旧调度；成功、路由/身份切换、组件卸载或显式取消均停止所属重试。区分登录态未确认和服务器明确返回未登录；只允许真实授权通过后的页面和链接。独立 Desktop 的 `GET /_desktop/api/session` 可能建立普通浏览器会话，继续按现有 Cookie 与 CSRF 核验；该恢复不允许携带任何业务写入或重放登录。

超时只表示本地不再等待，不表示服务端操作失败。写入请求不纳入只读重试器；响应丢失时保留原提交身份和 unknown 锁，按现有接口只读核对。首管理员创建先核对初始化状态，登录先核对会话；Admin 与 Desktop 核对原操作/对象。不能确认时保留未知状态和显式检查方向。进入应用后网络恢复只刷新受影响区域，遵守视图身份、草稿、焦点和敏感清理规则。

管理写入收到 `CORE_UNAVAILABLE` 时，浏览器不能据此区分转发前不可达与 Core 已提交但响应丢失，因此保守进入结果未知及原目标回读。引导登录的未知记录仅在内存保留原提交账号与身份归属，不保存密码；其他账号的真实会话不能确认原登录，也不能解除原提交锁或触发该次登录的后续导航。

## Risks / Trade-offs

- [CSP 哈希与产物不同步会阻断监测] → 由构建生成哈希并在真实 HTTP 响应验证，静态恢复入口始终保留；不改变其他策略。
- [慢设备在十秒后触发重载] → 限制两次并使用退避，应用一接管立即取消；不等待网络就提供可恢复壳。
- [请求超时后服务端仍在执行] → 只对指定读取自动恢复；写入结果未知严格回读，不重发或虚称失败。
- [保守的存储不可用降级无法自动重载] → 不冒无限循环风险，提供无需脚本的手动入口。
- [不同部署模式的导航或状态有差异] → 根据托管／独立模式及已确认权限提供目的地，保留原 URL 与身份边界。

## Migration Plan

先在本仓库实现并构建浏览器资源与宿主程序，通过模拟故障和真实 HTTP 路由测试；再与 MicroVM 的同名变更生成的 Windows 产物组合验证。上线不要求数据迁移或新增配置；回退应用程序恢复原有资源与行为，不能将历史制品重标为已修复。此计划不包含对外发行。
