# Spec Delta

## ADDED Requirements

### Requirement: 三个浏览器入口在启动依赖失败时有界恢复

Desktop、管理及登录／首次引导入口 SHALL 在成功取得入口 HTML 后监测关键启动资源和应用接管；关键模块或样式加载失败、执行失败或启动迟迟未完成时 SHALL 显示真实未确认状态和可执行恢复，不得永久停在纯 Loading。监测与静态手动恢复 MUST NOT 依赖同一可失败的外部模块图；即使所有外部脚本或样式不可用，用户仍能以键盘访问当前入口的手动重新加载按钮，以及当前部署模式的合法首页／返回入口。入口 HTML 自身无法取得不在网页脚本可恢复范围内。

应用尚未接管且尚未开放用户交互时，入口 SHALL 对启动失败进行有间隔、总次数有上限的自动恢复；默认每次启动周期最多自动重新加载两次，并在自动恢复耗尽后保留状态和手动重试。计数 MUST 在重载之间保持以避免无限循环，不得保存账号、密码、令牌、表单或业务数据；计数无法可靠保持时 MUST 停止自动重载并保留手动入口。成功接管后 SHALL 结束该周期的计数和定时器，后续显式重试只在用户发起时执行。

应用一旦接管并开放交互，MUST NOT 为后台读取、资源失败或网络恢复自动整页重载、跳转或重建整个应用；受影响的区域按各能力的读取恢复规则处理。恢复 SHALL 保持合法的当前路径、查询和目标，不能绕过认证、权限、Host/Origin 或既有输入保护。等待、失败和重试的文案 SHALL 遵守既有双语与加载状态规范，未获得语言模块时 SHALL 有可理解的静态中英文回退。

#### Scenario: 模块图中的资源暂时失败
- **WHEN** 任一入口的 HTML 已取得，但应用模块或其间接依赖首次加载失败，网络在自动恢复预算内恢复
- **THEN** 不需要用户刷新即可重新加载完整模块图并进入该入口，自动次数受限，成功后不再重载。

#### Scenario: 监测模块或样式自身不可用
- **WHEN** 外部启动脚本、翻译模块或样式无法取得，或关闭脚本执行
- **THEN** 原 HTML 仍提供可操作的中英文手动重载及合法首页／返回入口；在脚本可执行且符合现有策略时自动恢复仍受同一预算约束，独立 Desktop 不显示其不支持的服务端登录地址。

#### Scenario: 连续失败或浏览器不允许计数
- **WHEN** 关键依赖持续失败，或浏览器禁止保存用于跨重载的有限次数计数
- **THEN** 自动恢复在预算耗尽或计数不可用时停止，页面保留明确提示和可重复使用的手动恢复入口，不陷入重载循环。

#### Scenario: 应用已接管后网络短暂中断
- **WHEN** 用户已能在入口输入、导航或处理工作区，随后发生读取或资源失败
- **THEN** 不自动整页重载或切换目标；原视图和受保护输入按既有身份与敏感清理规则保留，失败由相应局部恢复处理。

#### Scenario: 完成与过期信号竞争
- **WHEN** 应用已接管或用户手动恢复，旧的启动超时、失败或重试信号随后到达
- **THEN** 旧信号不再重载页面、覆盖当前状态或破坏当前目标；成功后下一次新的启动周期仍可恢复。
