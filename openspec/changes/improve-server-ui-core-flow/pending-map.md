## 4. 不遗漏的独立状态和观察边界

- D07还包括Chat Activity/tool Running汇总，源码 `apps/desktop-webui/src/app.ts:913-920`；当前Activity主状态一处动画，保留已展开输出，不让每条历史tool同时动画。
- D11单个Download file实际直接交给浏览器（app.ts:2300-2302），没有落盘回报；只表示可观察的发起，不能伪造保存进度。Work导出受管job按D14保留真实阶段。
- D16 waiting_result/waiting_apply需说明实际waitRef，静态pendingApply、人工等待、暂停、unknown/failed不当作仍在网络请求；真实被观察的业务任务进行态仍可显示任务级三点。
- Core未HTTP监听时无产品网页；Desktop连接检查和HTTP后Runtime准备有现成UI。本变更不新增提前HTTP壳、Core启动器或持续离线自动重连。
- 每位置记录接入对象和所复用的测试；独立状态分支补针对性的开始/结束、错误/unknown或晚响应断言。共用锁/连续性沿现有代表测试回归，不为31位置分别复制所有分支的笛卡尔积，也不用截图代替状态断言。
- 固定占位/1.2秒/reduced-motion/Modal无动画使用统一组件测试；各入口测试确认接入且真实状态驱动，避免复制31套动画实现。
