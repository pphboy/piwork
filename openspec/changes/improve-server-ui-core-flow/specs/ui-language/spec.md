# Spec Delta

> M04 的共享表现规则；既有业务状态、对象锁及未知结果恢复继续引用 UIL-008/009 等有效规格，不由三点组件重做。

## ADDED Requirements

### Requirement: 浏览器异步等待使用统一局部三点

**Identifier:** UIL-PENDING-001

Server 首次引导、Admin、高级独立 Console、托管工作台与本机 CLI Desktop 的所有真实 Pending SHALL 使用同一局部三点规则：三点依次淡入淡出，每组透明度循环为 1.2 秒，固定尺寸占位；只有点的透明度变化，文字、按钮和容器不因动效位移、伸缩或旋转。1.2 秒不是最短等待时间，快速成功不得人为延迟。Modal 开合 SHALL 保持无动画，不为统一 Pending 引入全局遮罩或强制等待弹窗。

明确请求在途 SHALL 将三点附着发起按钮、目标对象标题或固定状态槽；首读无数据 SHALL 在稳定内容框架内展示一个所属等待状态，有已确认内容时 SHALL 保留正文并原位更新。一个任务只呈现一个主要等待动画；相互独立的并发对象可以各自局部显示，同一后台定时读取不得使各卡片反复独立闪动。跨端共享此规则不将 Serve 的页面宽度、表单网格或导航结构强加给 Desktop。

请求 busy 与已接受远程任务的 pending/running SHALL 保留区别及真实对象/阶段；取消请求仍在途时不得宣称已取消。真实任务执行或服务端明确自动重试期间可以持续任务级等待，保留原 ID、原因和实际重试信息。成功、明确失败、确认取消、暂停、不再等待、结果未知或需要用户输入时 SHALL 停止对应等待动画，显示准确结果/恢复方向；停止动画不自动解除未知写入锁。静态待应用、离线、缺配置、授权缺失不伪装为进行中。

十秒以上未取得新确认 SHALL 在原状态区说明仍等待的对象/阶段及可用检查或恢复方向，不虚构超时失败、百分比、速度或完成时间；实际读取超时/失败 SHALL 转为可恢复状态并保留最后确认事实，不能无限动效掩盖已失败请求。正常后台轮询不逐次播报或周期性重启三点；正在观察的真实长任务仍可保持主要等待指示。

真实已知传输进度 SHALL 保留字节数/进度条；三点只补充不可量化的请求、准备、验证或确认等待，不取代真实进度、不声称浏览器已落盘。状态区域 SHALL 有可访问动作说明与适当 busy/状态语义，装饰三点不重复播报；减少动态效果偏好 SHALL 提供静态三点/文字且保持可辨。动效更新不能重建输入、清空草稿、抢焦点、移动阅读位置或重挂 Service iframe。

本要求覆盖所有 Piwork 可观察的异步入口，包括独立于通用动作组件的初始壳、会话/Core检查、模型读取/自动保存、图片、Activity、默认Core与About；普通即时导航、菜单、搜索、复制不因统一规则被强制添加等待。浏览器原生加载/下载界面和第三方 Service 内部动效不在可控范围，不伪造它们的完成状态。

#### Scenario: 三点循环与固定位置
- **WHEN** 用户触发一个尚未返回的保存或读取请求
- **THEN** 原操作固定槽显示依次透明度变化的三点，周期为1.2秒；按钮、标签和邻近布局尺寸位置不因循环改变，结果到达即结束而不等满周期

#### Scenario: 首读与已有数据更新
- **WHEN** 同一路由先无已确认内容，之后在有正文时手动刷新
- **THEN** 首次显示稳定框架及所属等待；再次刷新保留正文、草稿、展开、焦点和滚动，只在既有状态槽显示当前读取

#### Scenario: 并发与背景轮询
- **WHEN** 两个独立对象分别有用户操作，同时后台轮询读取当前页面
- **THEN** 两个操作各在本对象呈现，不互相加全局遮罩；同对象读取协调去重，后台更新不制造多卡片闪动或逐次通知

#### Scenario: 长任务及终态
- **WHEN** 任务已接受并执行，随后成功、明确失败、确认取消、暂停或转入结果未知
- **THEN** 执行时显示原对象阶段和任务级三点，进入所述非进行态后停止动画并给正确结果/恢复；未知写入不因动画停止自动重发或解锁

#### Scenario: 长等待与真实错误
- **WHEN** 请求超过十秒仍在等待，随后出现实际超时或连接错误
- **THEN** 先在原区域解释等待而不假造失败，真实错误后停止该请求动画、保留最后状态及只读恢复入口，合法返回和独立操作仍可用

#### Scenario: 进度与浏览器下载交接
- **WHEN** 文件传输有真实字节进度，之后已交给浏览器下载
- **THEN** 保留进度值及准确阶段，不能用三点替代可量化数据；交接后只说明已发起下载，不继续假装观察本地落盘

#### Scenario: 减少动态效果与Modal
- **WHEN** 用户启用减少动态效果，或在含异步操作的Modal中提交/关闭
- **THEN** 等待使用静态可辨的点与文字；Modal本身不开合动画，既有焦点、关闭/取消和危险操作语义不改变

#### Scenario: 缺少运行条件不伪装为启动
- **WHEN** Core离线、Runtime缺配置、浏览器需要授权或配置只是等待用户Apply
- **THEN** 显示具体静态状态和可执行方向；只有真实检查或任务在进行时显示所属三点，不承诺页面自行启动Core
