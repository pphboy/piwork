# NiceGUI 页面开发与排障

在 NiceGUI 页面创建、修改或异常排查时按需读取。沿当前任务与现有 Service 部署/验证路径工作，不创建额外设计报告、审批、Agent 目标或新运行时。

## 样式隔离

自定义类按业务命名，例如 `.todo-app-root`、`.todo-app-card`，尽量以应用根容器限定范围，例如 `.todo-app-root .todo-app-card`。不要定义无范围的 `.column`、`.row`、`.card` 等规则，避免影响 NiceGUI 或其组件的布局；同样不要全局覆盖实际观察到的 `.nicegui-column`、`.nicegui-row` 等框架类。保留框架自带的行/列和内部容器类；必要的框架组件覆盖只针对应用范围内的明确目标，并核对实际效果。有意的文档级背景/字体主题可以保留。

默认 web-app/workstation 模板分别采用 `webapp-` / `workstation-` 前缀。修改时同步 Python 的 classes 和 CSS 选择器，沿原页面输入清单及 Service 流程生效，不为命名整理重做布局或增加设计系统。

## 从真实入口验收

先确认当前 Work 实际可用且获准的浏览器工具/访问范围。能力存在时，通过用户使用的 Desktop Service 入口观察受影响页面，确认主要内容可见、操作确实可执行、用户及 Agent 的业务变化自动出现。检查真实入口的授权、iframe 与 HTTP/WebSocket 路径，而不只打开 Service 直接地址。

Service Ready、HTTP 200、Query/Action 成功和代码版本已更新各自只证明一层；内容被隐藏或操作被遮挡时，页面仍未通过。业务数据同步与代码版本自动采用分别核对，更新不应清掉无关草稿、焦点或当前操作。查询失败应表达观察失败/数据可能陈旧，恢复后重新取得权威结果，不通过重部署、手动刷新或额外模型 Run 掩盖故障。

没有获准浏览器能力、入口不可达或未获授权时，明确“页面未验证”、原因和已确认的后端结果，不声称完整 UI 交付。不擅自安装浏览器或 MCP、扩大权限、读取用户票据/凭据或绕过入口授权。平台开发测试有 Playwright 不能替代当前 Work 的实际能力。仅验收受影响页面，不要求全页面巡检、固定截图或视觉评分。

## 空白与不可操作页面的证据

按现象选择必要观察，保留安全的结果和时点：

- 资源：请求是否发出、返回状态、实际资源类型及加载结果；200 的页面入口不等于所有脚本/样式都加载。
- 浏览器错误：实际异常及相关模块，不把无关警告当作根因。
- 连接：HTTP/WebSocket 是否可用、是否中断/重连，实际入口是否拒绝当前身份。
- DOM：业务内容是否存在；存在但不可见与尚未生成分别判断。
- 样式与尺寸：目标及必要祖先的 display、visibility、opacity、实际宽高，是否被通用布局类覆盖。
- 遮罩：层叠关系、pointer-events、目标位置上的实际元素；内容可见但无法点击也未通过。

DOM 存在、资源/连接正常而计算样式隐藏内容时，修复有证据支持的样式/尺寸原因；遮罩阻挡时检查其实际来源。资源、脚本或连接异常则处理对应层，不只改 CSS。没有足够证据时保留原因未知，不直接判定 NiceGUI/iframe 架构不兼容，也不默认换栈。

诊断不得泄漏 ticket、token、私有 URL 参数或无关用户内容。必要修复后回到原 Desktop Service 入口，复查相关内容、操作和状态；修改文件或换框架本身不是修复完成的证明。历史失败结果保留，合成夹具的固定分发不能证明任意模型都会自主正确归因。

## 托管浏览器的动态前缀

浏览器 Service 入口为 ControlPlane 的 `/services/<workId>/<serviceId>/<port>/`，不直接连接 Core、容器或额外宿主端口。NiceGUI 使用请求 `X-Forwarded-Prefix` 处理内置链接、资源与 Socket.IO，框架组件不要重复加前缀。官方 `page_head(ui, loaded)` 为自定义资源/版本/反馈提供同一请求上下文；自定义 fetch 使用 `window.piworkAppURL('/path')`，Python 自定义 HTML 资源用 `browser_url(request, '/path')`。不要持久写入 IP 或 Work/Service ID。容器内 `/health`、`/pi/v1` 和 Agent 请求仍用根路径。

应用与工作台同源，按当前用户信任的应用处理，不宣称路径隔离 DOM/存储或当前用户 UI 权限。草稿/反馈使用运行时提供的会话与目标命名空间；响应 Cookie 由代理分区，脚本 Cookie 不同步。旧固定镜像/源码不会随导入自动迁移；显式适配旧应用后再从真实前缀入口验证。
